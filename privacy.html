What ContribMatch stores

ContribMatch is a static site. There is no application server, no database and no analytics script. The only things that persist are the files below, and they never leave your browser unless you ask them to.

Stored in your browser

What Where Why How to remove it
Your shortlist localStorage So your saved issues survive a reload “Clear shortlist” on the shortlist page
Cached GitHub responses localStorage So a repeat search does not spend your rate limit Clear site data for this origin
Your preferences localStorage Provider, model, theme and language Clear site data for this origin
GitHub token sessionStorage To raise the GitHub rate limit Close the tab, or press “Forget the key and the token”
AI Studio key sessionStorage To call the hosted model Close the tab, or press “Forget the key and the token”

What is sent, and where

  • To GitHub (api.github.com) — your username, and the search terms ContribMatch builds for you. All of it is public data.
  • To your model — with Ollama, to localhost on your own machine. With Google AI Studio, to Google. What is included: the issue title, body and labels of the shortlist, plus your inferred skills and level. Nothing else. No token, no key, no shortlist.
  • Never — ContribMatch never posts a comment, a branch or a pull request, and never writes to GitHub with your token.

About the model

Issue text and README text are untrusted. ContribMatch wraps them in a clearly marked block and tells the model that the block is data, not instructions. The model is never asked to execute anything from an issue.

Even so, a hosted model is a third party. If that matters to you, run the model locally with Ollama and nothing you read is sent off the machine.

Children

ContribMatch is a developer tool and collects no personal data from anyone, including children. Because there is no backend, there is no account to create and no profile to delete.
