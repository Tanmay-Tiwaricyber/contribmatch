Packs

Add a pack

json 
{
  "id": "my-pack",
  "name": "My pack",
  "type": "skill",
  "version": "1.0.0",
  "description": "What this pack is for, in one or two sentences.",
  "languages": ["en"],
  "skills": ["python", "testing"],
  "tone": "plain",
  "level": "beginner"
}
  1. Create packs/my-pack.pack.json (or .yaml).
  2. Run npm run validate:packs.
  3. Add the file to PACK_FILES in js/core/packs.js.
  4. Open a pull request that explains which projects the pack helps with.
