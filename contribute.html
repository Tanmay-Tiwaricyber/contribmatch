Start with a starter issue

Fifteen starter issues are listed in docs/GOOD_FIRST_ISSUES.md. They cover packs, translations, interface work, tests and documentation, and five of them are design tasks. Comment on the issue before you start so two people do not do the same work.

Set the project up

bash
git clone https://github.com/contribmatch/contribmatch.git
cd contribmatch
npm install          # dev tools only: the app itself needs nothing
npm test             # runs the whole test suite
python3 -m http.server 8080

The app has no build step. npm install only pulls the development tools (the screenshot script and the accessibility audit). The site itself is plain HTML, CSS and ES modules.

The pull request workflow

  1. Fork the repository and create a branch from main.
  2. Read CONTRIBUTING.md — especially the design rules below.
  3. Make the change, and run npm test before you push.
  4. Open a pull request that says what changed and why, and link the issue.

Design contribution rules

ContribMatch has a strict visual language. These rules are not preferences; a pull request that breaks them will be asked to change.

  • One accent colour only: #2d81ff. No second accent, no gradients, no glows, no glassmorphism.
  • Type is Archivo for display, Instrument Serif italic for one emphasised phrase per heading, Geist Mono for labels and numbers, Inter for body text.
  • An 8px spacing rhythm, with 4px fine tuning. Borders are 1px and crisp.
  • Every interactive element needs a visible :focus-visible state and a touch target of at least 44px.
  • Contrast is checked: body text at 4.5:1, controls and graphics at 3:1. Run node tools/contrast.mjs --strict.
  • Motion is under 250ms, purposeful, and disabled under prefers-reduced-motion.
  • No emoji as decoration. No invented statistics, testimonials or logos.
  • Copy is plain and specific. Banned words: revolutionise, supercharge, seamless, unlock.

The living style guide, with measured contrast ratios, is at design-system.html.

Adding something new

  • A community pack — see packs. JSON or YAML, validated by npm run validate:packs.
  • A translation — add or extend a file in js/i18n/. Every key in en.js must exist in all three dictionaries.
  • A test — tests live in tests/ and run with node --test.

Code of conduct

ContribMatch follows the Contributor Covenant. Be patient with beginners, including beginners on the project itself. That is the whole point of it.

Questions first

If something is unclear, open an issue and ask. A question costs nothing and the answer helps the next person.
